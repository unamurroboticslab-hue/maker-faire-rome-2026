Welcome to the Maze Challenge! 🤖

      
Bienvenue dans le défi du labyrinthe !


      

        

          
🇬🇧 English

          
In this activity, you will program a real robot to navigate through a corridor without hitting walls or obstacles. You do this by assembling blocks — like building with LEGO — each block representing one action the robot will perform.

          
The goal is to reach the end of the corridor by finding the right sequence of movements and the right timing.

        

        

          
🇫🇷 Français

          
Dans cette activité, vous allez programmer un vrai robot pour traverser un couloir sans heurter les murs ou les obstacles. Vous faites cela en assemblant des blocs — comme construire avec des LEGO — chaque bloc représentant une action que le robot va effectuer.

          
L'objectif est d'atteindre l'extrémité du couloir en trouvant la bonne séquence de mouvements et le bon minutage.

STRATEGY SELECTOR / SÉLECTEUR DE STRATÉGIE

        

          

            

              
📋 Blind Sequence

              
🇬🇧 The robot follows a fixed list of moves in order, with no sensor feedback. Like giving someone directions step by step.

              
🇫🇷 Le robot suit une liste fixe de mouvements dans l'ordre, sans retour des capteurs. Comme donner des directions étape par étape.

            

            

              
🧠 Reactive

              
🇬🇧 The robot continuously reads its sensors and reacts to what it detects — obstacles, walls, the goal. More autonomous.

              
🇫🇷 Le robot lit continuellement ses capteurs et réagit à ce qu'il détecte — obstacles, murs, objectif. Plus autonome.

🧩 Block Reference / Référence des blocs

      
🇬🇧 Each block represents one instruction for the robot. Click the number inside a block to change it.
🇫🇷 Chaque bloc représente une instruction pour le robot. Cliquez sur le nombre dans un bloc pour le modifier.


      
      
Move Blocks / Blocs de mouvement


      

        

          ⬆️
          Move Forward / Avancer
          dur (sec)
        

        
🇬🇧 Moves the robot straight forward for a given number of seconds. Increasing the duration moves the robot further.
Example: dur = 2.0 → robot moves forward for 2 seconds.

        
🇫🇷 Fait avancer le robot tout droit pendant un nombre de secondes donné. Augmenter la durée fait avancer le robot plus loin.
Exemple : dur = 2.0 → le robot avance pendant 2 secondes.

      


      

        

          ⚡
          Set Speed / Régler la vitesse
          spd (%)
        

        
🇬🇧 Sets the robot's speed as a percentage (10%–100%). Place this block before any forward or turn blocks. A lower speed gives you more precision.
Example: spd = 50 → robot moves at half speed.

        
🇫🇷 Définit la vitesse du robot en pourcentage (10%–100%). Placez ce bloc avant les blocs avancer ou tourner. Une vitesse plus faible donne plus de précision.
Exemple : spd = 50 → le robot se déplace à mi-vitesse.

      


      
      
Turn Blocks / Blocs de rotation


      

        

          ↰
          Turn Left / Tourner à gauche
          deg (°)
        

        
🇬🇧 Rotates the robot to the left by a given number of degrees. 90° = quarter turn, 180° = half turn.
Example: deg = 90 → robot turns left by 90 degrees.

        
🇫🇷 Fait pivoter le robot vers la gauche d'un nombre de degrés donné. 90° = quart de tour, 180° = demi-tour.
Exemple : deg = 90 → le robot tourne à gauche de 90 degrés.

      


      

        

          ↱
          Turn Right / Tourner à droite
          deg (°)
        

        
🇬🇧 Rotates the robot to the right by a given number of degrees.
Example: deg = 90 → robot turns right by 90 degrees.

        
🇫🇷 Fait pivoter le robot vers la droite d'un nombre de degrés donné.
Exemple : deg = 90 → le robot tourne à droite de 90 degrés.

      


      
      
Control Blocks / Blocs de contrôle


      

        

          🔁
          Repeat / Répéter
          n (×)
        

        
🇬🇧 Repeats the previous block's action N times. Useful to avoid copying the same block multiple times.
Example: n = 3 → the action above is repeated 3 times.

        
🇫🇷 Répète l'action du bloc précédent N fois. Utile pour éviter de copier le même bloc plusieurs fois.
Exemple : n = 3 → l'action ci-dessus est répétée 3 fois.

      


      
      
Sensor Blocks / Blocs capteurs (Reactive only)


      

        

          🧠
          Braitenberg Avoid / Évitement Braitenberg
          sensitivity
        

        
🇬🇧 Uses the proximity sensors to automatically steer away from walls and obstacles. Higher sensitivity = stronger avoidance reaction.
Example: sens = 1.5 → moderate avoidance.

        
🇫🇷 Utilise les capteurs de proximité pour s'écarter automatiquement des murs et obstacles. Sensibilité plus élevée = réaction d'évitement plus forte.
Exemple : sens = 1.5 → évitement modéré.

      


      

        

          🚧
          If Obstacle → Turn Away / Si obstacle → tourner
          threshold
        

        
🇬🇧 If the front proximity sensors detect an obstacle above the threshold value, the robot turns away from it automatically.
Example: thr = 500 → turns away when obstacle is close.

        
🇫🇷 Si les capteurs de proximité frontaux détectent un obstacle au-dessus de la valeur seuil, le robot s'en éloigne automatiquement.
Exemple : thr = 500 → tourne quand l'obstacle est proche.

      


      
      
Goal Block / Bloc objectif


      

        

          🎯
          If on Goal → Stop / Si sur l'objectif → arrêter
          threshold
        

        
🇬🇧 Detects the black tape at the end of the corridor using the ground sensor. When the robot crosses it, it stops and celebrates! Place this block at the end of your program.
Example: thr = 500 → triggers when the ground is darker than 500.

        
🇫🇷 Détecte le ruban noir au bout du couloir grâce au capteur de sol. Quand le robot le traverse, il s'arrête et célèbre ! Placez ce bloc à la fin de votre programme.
Exemple : thr = 500 → se déclenche quand le sol est plus sombre que 500.

💡 Tips & Tricks / Astuces


      

        
📐 Calculating Forward Duration / Calculer la durée d'avancement

        
🇬🇧 The key challenge is figuring out how long the robot needs to move forward to reach each checkpoint tape. Here's the formula:

        
🇫🇷 Le défi principal est de déterminer combien de temps le robot doit avancer pour atteindre chaque ruban. Voici la formule :

        

          
duration (s) = distance (cm) / speed (cm/s)

          
At 50% speed, the robot moves approximately 15–18 cm/s / À 50% de vitesse, le robot avance environ 15–18 cm/s

        

        
🇬🇧 Example: First checkpoint is at 40 cm. At 50% speed (~16 cm/s): 40 ÷ 16 ≈ 2.5 seconds. Start with 2.5s and adjust from there!

        
🇫🇷 Exemple : Premier checkpoint à 40 cm. À 50% de vitesse (~16 cm/s) : 40 ÷ 16 ≈ 2.5 secondes. Commencez par 2.5s et ajustez !

      


      

        
🔄 Calculating Turn Duration / Calculer la durée de rotation

        
🇬🇧 A 90° turn at default speed takes approximately 0.66 seconds. The block uses degrees — just enter the angle you want.

        
🇫🇷 Un virage à 90° à la vitesse par défaut prend environ 0.66 secondes. Le bloc utilise les degrés — entrez simplement l'angle souhaité.

      


      

        
🔁 Using the Timer / Utiliser le chronomètre

        
🇬🇧 Watch the elapsed timer when the robot is running. If the robot takes 3.2s to reach the first tape, try setting your first forward block to 3.2s next time!

        
🇫🇷 Observez le chronomètre pendant que le robot avance. Si le robot prend 3,2s pour atteindre le premier ruban, essayez de mettre 3,2s dans votre premier bloc avancer !

      


      

        
⚡ Start Slow! / Commencez lentement !

        
🇬🇧 Always start with a low speed (30–50%). A slower robot is easier to observe, gives you more time to react, and is less likely to crash hard into walls.

        
🇫🇷 Commencez toujours avec une vitesse faible (30–50%). Un robot plus lent est plus facile à observer, vous donne plus de temps pour réagir, et a moins de risques de percuter violemment les murs.

      


      

        
🎯 Goal Detection / Détection de l'objectif

        
🇬🇧 Always place the 🎯 If on Goal block at the very end of your program. The robot will keep moving until it detects the final black tape, then stop and celebrate automatically.

        
🇫🇷 Placez toujours le bloc 🎯 Si sur l'objectif tout à la fin de votre programme. Le robot continuera à avancer jusqu'à ce qu'il détecte le ruban noir final, puis s'arrêtera et célébrera automatiquement.
