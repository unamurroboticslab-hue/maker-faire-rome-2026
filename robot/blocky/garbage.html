Welcome to the Garbage Collector! 🗑🤖

      
Bienvenue dans le Ramasseur de Déchets !


      

        

          
🇬🇧 English

          
In this activity, you will program a robot to autonomously collect garbage boxes scattered in an arena. The robot must wander, detect each box with its sensors, push it across the boundary line, and return to collect more — all without falling outside the arena itself!

          
The more boxes you collect and the fewer collisions you have, the higher your score.

        

        

          
🇫🇷 Français

          
Dans cette activité, vous allez programmer un robot pour collecter de manière autonome des boîtes dispersées dans une arène. Le robot doit errer, détecter chaque boîte avec ses capteurs, la pousser hors de la limite, puis revenir en chercher d'autres — sans sortir lui-même de l'arène !

          
Plus vous collectez de boîtes et moins vous avez de collisions, plus votre score est élevé.

🔑 Key Concept / Concept clé

        
🇬🇧 The robot runs your blocks in a continuous loop. Every iteration it first checks the boundary (black tape), then executes your blocks in order. The loop never stops — it just keeps wandering and collecting until you press STOP.

        
🇫🇷 Le robot exécute vos blocs en boucle continue. À chaque itération, il vérifie d'abord la limite (ruban noir), puis exécute vos blocs dans l'ordre. La boucle ne s'arrête jamais — il continue d'errer et de collecter jusqu'à ce que vous appuyiez sur STOP.

🧩 Block Reference / Référence des blocs

      
🇬🇧 Blocks run in a continuous loop — order matters! / 🇫🇷 Les blocs s'exécutent en boucle continue — l'ordre est important !


      
      
Move Blocks / Blocs de mouvement


      

        

          ⚡
          Set Speed / Régler la vitesse
          spd (%)
        

        
🇬🇧 Sets the robot's base movement speed (10–100%). Place this block near the top of your program. Lower speed = more control, easier to detect garbage.
Example: spd = 50 → half speed.

        
🇫🇷 Définit la vitesse de base du robot (10–100%). Placez ce bloc en haut de votre programme. Vitesse plus faible = plus de contrôle, détection plus facile.
Exemple : spd = 50 → mi-vitesse.

      


      

        

          🌀
          Random Wander / Errance aléatoire
          dur · turn% · turn ms
        

        
🇬🇧 Makes the robot move forward for dur seconds, then randomly turns with probability turn%. This is how the robot explores the arena. The boundary is checked on every step — the robot will back up and turn if it hits the edge.
Parameters: dur = straight duration, turn_chance = probability of turning, turn_dur = how long the turn lasts.

        
🇫🇷 Fait avancer le robot pendant dur secondes, puis tourne aléatoirement avec une probabilité turn%. C'est ainsi que le robot explore l'arène. La limite est vérifiée à chaque pas — le robot reculera et tournera s'il touche le bord.

      


      

        

          🔍
          Scan & Approach / Scanner et approcher
          scan_thr · scan_spd · reposition · approach_spd
        

        
🇬🇧 A three-phase block: Phase 1 — spins 360° slowly using the ToF sensor to find a box. Phase 2 — approaches it with steering to stay centered. Phase 3 — if nothing found, moves forward briefly to reposition. More advanced than wander alone.
scan_thr: detection distance (cm). approach_spd: speed while approaching.

        
🇫🇷 Un bloc en trois phases : Phase 1 — tourne à 360° lentement en utilisant le capteur ToF pour trouver une boîte. Phase 2 — s'en approche avec direction pour rester centré. Phase 3 — si rien trouvé, avance brièvement pour se repositionner.

      


      
      
Turn Blocks / Blocs de rotation


      

        

          ↰ ↱
          Turn Left / Right — Tourner gauche / droite
          deg (°)
        

        
🇬🇧 Rotates the robot by a fixed number of degrees. Useful to manually steer in Engineer mode.
Example: deg = 90 → quarter turn.

        
🇫🇷 Fait pivoter le robot d'un nombre fixe de degrés. Utile pour diriger manuellement en mode Engineer.
Exemple : deg = 90 → quart de tour.

      


      
      
Sensor Blocks / Blocs capteurs


      

        

          🚫
          Boundary Sensitivity / Sensibilité de limite
          thr
        

        
🇬🇧 Sets the ground sensor threshold for detecting the black boundary tape. Lower value = robot must be more directly over the tape to react. Higher value = reacts from further away. Place this block at the very top.
Default: 500. Increase if the robot ignores the boundary; decrease if it reacts too early.

        
🇫🇷 Définit le seuil du capteur de sol pour détecter le ruban noir de limite. Valeur plus basse = le robot doit être plus directement sur le ruban. Placez ce bloc tout en haut.

      


      

        

          🚧
          If Obstacle → Turn Away / Si obstacle → tourner
          thr
        

        
🇬🇧 When the front proximity sensors detect an obstacle above the threshold, the robot turns away. Only active when not already pushing.
Example: thr = 150 → reacts to close objects.

        
🇫🇷 Quand les capteurs de proximité frontaux détectent un obstacle au-dessus du seuil, le robot s'en éloigne. Actif seulement quand il ne pousse pas.

      


      

        

          ↔️
          Turn Toward Side Garbage / Tourner vers déchet latéral
          thr
        

        
🇬🇧 Checks the left and right proximity sensors (ps2, ps5). If garbage is detected on the side, the robot turns to face it before approaching.
Best used after wander and before find_garbage.

        
🇫🇷 Vérifie les capteurs gauche et droite (ps2, ps5). Si un déchet est détecté sur le côté, le robot tourne pour lui faire face avant d'approcher.

      


      

        

          🎯
          Align to Garbage / Aligner sur le déchet
          thr · align_thr
        

        
🇬🇧 When a garbage box is detected, makes micro-corrections to center the robot directly in front of it before pushing. Improves push accuracy.
align_thr: how precise the centering needs to be (lower = more precise but slower).

        
🇫🇷 Quand une boîte est détectée, fait des micro-corrections pour centrer le robot directement devant elle avant de pousser. Améliore la précision du poussage.

      


      
      
Garbage Blocks / Blocs déchet


      

        

          🗑
          If Garbage Found → Push / Si déchet trouvé → pousser
          thr · pushspd (%)
        

        
🇬🇧 Detects garbage using the 4 front proximity sensors (ps0, ps1, ps6, ps7). When a box is found, activates push mode and drives forward while steering to stay centered on the box.
thr: detection threshold. pushspd: speed while pushing.

        
🇫🇷 Détecte les déchets avec les 4 capteurs de proximité frontaux. Quand une boîte est trouvée, active le mode poussée et avance en restant centré sur la boîte.
thr : seuil de détection. pushspd : vitesse pendant la poussée.

      


      

        

          💨
          Push Until Boundary / Pousser jusqu'à la limite
          timeout (s)
        

        
🇬🇧 Manages the push operation. Monitors the ground sensor and proximity sensors to determine when to stop pushing. Four outcomes:

        
    
          
  • COLLECTED — boundary reached after >1s → garbage pushed out! +10 pts
    • 
          
  • FALSE_BOUNDARY — boundary reached too fast → robot was already near edge, backs up
    • 
          
  • LOST_GARBAGE — box lost contact → resumes wandering
    • 
          
  • PUSH_TIMEOUT — timeout reached → gives up and resumes wandering
    • 
        

        
🇫🇷 Gère l'opération de poussée. Surveille les capteurs pour déterminer quand arrêter. timeout : durée maximale de poussée avant abandon.

      


      
      
Celebrate & Control / Célébration et contrôle


      

        

          🎉
          Celebrate + Score Point / Célébrer + point de score
        

        
🇬🇧 A placeholder block that marks where the score update happens. The actual celebration (LED flash + beep) is triggered automatically when the robot receives the COLLECTED message. Place this after push_out.
🇫🇷 Un bloc indicateur qui marque où la mise à jour du score se produit. La célébration réelle est déclenchée automatiquement quand le robot reçoit le message COLLECTED. Placez-le après push_out.

      


      

        

          🔁
          Repeat / Répéter
          n (×)
        

        
🇬🇧 Repeats the loop iteration N extra times, effectively giving the robot more time steps before moving to the next block.
🇫🇷 Répète l'itération de boucle N fois supplémentaires, donnant au robot plus de pas de temps avant de passer au bloc suivant.

      

    


    
    

      
🏟️ The Arena / L'arène


      

        

          
🇬🇧 The arena is a flat square area delimited by a black tape boundary on the floor. Garbage boxes are scattered randomly inside.

          
    
            
  • The robot must stay inside the boundary
    • 
            
  • Garbage boxes must be pushed outside the boundary
    • 
            
  • The robot uses its ground sensor to detect the black tape
    • 
            
  • The robot uses its proximity sensors to detect boxes
    • 
          

        

        

          
🇫🇷 L'arène est une zone carrée plane délimitée par un ruban noir au sol. Des boîtes sont dispersées aléatoirement à l'intérieur.

          
    
            
  • Le robot doit rester à l'intérieur de la limite
    • 
            
  • Les boîtes doivent être poussées à l'extérieur de la limite
    • 
            
  • Le robot utilise son capteur de sol pour détecter le ruban noir
    • 
            
  • Le robot utilise ses capteurs de proximité pour détecter les boîtes
    •

  • 🇬🇧 If the robot itself crosses the boundary, it counts as a collision (−2 pts).
    • 
          
  • 🇫🇷 Si le robot lui-même sort de la limite, cela compte comme une collision (−2 pts).
    • 
          
  • 🇬🇧 Only garbage pushed across the boundary (not just touching the tape) counts as collected.
    • 
          
  • 🇫🇷 Seuls les déchets poussés au-delà de la limite comptent comme collectés.
    • 
          
  • 🇬🇧 Set the garbage count in the right panel to match the actual number of boxes in the arena.
    • 
          
  • 🇫🇷 Définissez le nombre de déchets dans le panneau droit pour correspondre au nombre réel de boîtes.

📊 Score Formula / Formule de score

        

          Score = (collections × 10) + bonus(5) − (collisions × 2)
        

        
🇬🇧 Example: 3 boxes collected, 0 collisions = 3×10 + 5 = 35 points

        
🇫🇷 Exemple : 3 boîtes collectées, 0 collision = 3×10 + 5 = 35 points

💡 Tips & Tricks / Astuces


      

        
✅ Recommended Block Order / Ordre recommandé des blocs

        

          
1. 🚫 Boundary Sensitivity — always first / toujours en premier

          
2. ⚡ Set Speed — set before moving / avant de bouger

          
3. 🌀 Random Wander — explore the arena / explorer l'arène

          
4. 🗑 If Garbage Found → Push — detect and push / détecter et pousser

          
5. 💨 Push Until Boundary — complete the push / terminer la poussée

          
6. 🎉 Celebrate — mark the score point / marquer le point

        

      


      

        
🔍 Tuning Detection Thresholds / Régler les seuils de détection

        
🇬🇧 If the robot doesn't detect garbage: lower the thr value (more sensitive). If it detects false positives (reacts to walls): raise the thr value. Start with 150 and adjust.

        
🇫🇷 Si le robot ne détecte pas les déchets : baissez la valeur thr (plus sensible). S'il détecte des faux positifs : augmentez thr. Commencez avec 150 et ajustez.

      


      

        
⚡ Speed vs Detection / Vitesse contre détection

        
🇬🇧 A fast robot covers the arena quickly but may miss garbage or overshoot pushes. A slow robot detects better but takes longer. Start at 50% and experiment.

        
🇫🇷 Un robot rapide couvre l'arène rapidement mais peut rater des déchets ou dépasser lors des poussées. Un robot lent détecte mieux mais prend plus de temps. Commencez à 50% et expérimentez.

      


      

        
🚫 Avoiding Collisions / Éviter les collisions

        
🇬🇧 The boundary check runs automatically before your blocks every loop. If the robot still exits, try: raising boundary_sens thr, reducing speed, or increasing wander turn_chance so it changes direction more often.

        
🇫🇷 La vérification de la limite s'exécute automatiquement avant vos blocs à chaque boucle. Si le robot sort quand même, essayez : augmenter le seuil boundary_sens, réduire la vitesse, ou augmenter turn_chance.

      


      

        
🔍 Advanced: Scan & Approach / Avancé : Scanner et approcher

        
🇬🇧 Replace Random Wander with Scan & Approach for a smarter robot. It uses the ToF sensor to actively search for boxes rather than wandering randomly. More efficient but harder to tune.

        
🇫🇷 Remplacez Errance aléatoire par Scanner et approcher pour un robot plus intelligent. Il utilise le capteur ToF pour rechercher activement des boîtes. Plus efficace mais plus difficile à régler.
